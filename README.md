# حِرفتي (HIRFATI)

**حِرفتي** موقع إلكتروني باللغة العربية يربط العملاء بالحرفيين داخل الأردن.
يستطيع العميل تصفّح الخدمات والحرفيين في المحافظات الأردنية الاثنتي عشرة، وإرسال طلب عرض سعر للحرفي،
ثم قبول العرض أو رفضه وتقييم الخدمة بعد إنجازها. ويدير الأدمن المستخدمين والطلبات والشكاوى والاشتراكات.

مشروع تخرج.

---

## التقنيات المستخدمة

| التقنية | الاستخدام |
|---|---|
| HTML | بناء صفحات الموقع (باتجاه RTL) |
| CSS | تنسيق الواجهة وتجاوبها مع الجوال |
| JavaScript | تفاعل الصفحات والاتصال بالواجهة الخلفية (API) |
| Python Flask | الواجهة الخلفية: الحسابات والصلاحيات والطلبات والعروض والاشتراكات |
| MySQL | قاعدة البيانات `hirfati_db` |
| Docker | تشغيل Flask وMySQL معاً بأمر واحد |
| GitHub | حفظ الكود ومشاركته وتحديثه |

## هيكل المشروع

```

│   ├── login.html            تسجيل الدخول
│   ├── register.html         إنشاء حساب عميل أو حرفي
│   ├── customer/             صفحات العميل (الرئيسية، الخدمات، الحرفيون، ملف الحرفي، طلباتي، الشكاوى)
│   ├── craftsman/            صفحات الحرفي (الملف الشخصي، الطلبات، الاشتراك، الشكاوى)
│   ├── admin/                لوحة تحكم الأدمن (المستخدمون، الطلبات، الشكاوى، الاشتراكات)
│   └── static/
│       ├── css/style.css     التنسيق العام
│       └── js/               ملفات JavaScript لكل نوع حساب + الاتصال بالـ API
├── backend/                  الواجهة الخلفية (Flask)
│   ├── app.py                نقطة تشغيل التطبيق
│   ├── config.py             الإعدادات (تُقرأ من متغيرات البيئة / ملف .env)
│   ├── database.py           الاتصال بقاعدة بيانات MySQL
│   ├── models.py             استعلامات قاعدة البيانات
│   ├── routes.py             مسارات الـ API والصفحات والتحقق من الصلاحيات
│   ├── payment.py            الدفع التجريبي لاشتراك Pro (بدون بوابة دفع حقيقية)
│   └── requirements.txt      مكتبات Python المطلوبة
├── database/
│   ├── schema.sql            إنشاء قاعدة البيانات والجداول والعلاقات
│   └── seed.sql              بيانات تجريبية (خدمات، حرفيون، عملاء، أدمن)
├── Dockerfile                بناء صورة تطبيق Flask
├── docker-compose.yml        تشغيل خدمتي Flask (web) وMySQL (db)
├── .env.example              أسماء متغيرات البيئة المطلوبة (بدون كلمات مرور)
├── .gitignore                الملفات التي لا تُرفع إلى GitHub
└── README.md                 هذا الملف
```

جداول قاعدة البيانات: `users`، `craftsman_profiles`، `services`، `craftsman_services`،
`requests`، `offers`، `reviews`، `complaints`، `subscriptions`.

## طريقة التشغيل باستخدام Docker

**1. تنزيل المشروع من GitHub**

```bash
git clone https://github.com/<اسم-المستخدم>/HIRFATI.git
```

**2. الدخول إلى مجلد المشروع**

```bash
cd HIRFATI
```

**3. إنشاء ملف `.env` بالاعتماد على `.env.example`**

Windows (PowerShell):

```powershell
Copy-Item .env.example .env
```

macOS / Linux:

```bash
cp .env.example .env
```

ثم افتح ملف `.env` واكتب قيماً خاصة بك في:
`MYSQL_PASSWORD` و`MYSQL_ROOT_PASSWORD` و`SECRET_KEY` (كلمات مرور قوية وعشوائية).
يمكنك كتابة أي نص طويل وعشوائي، أو توليده بالأمر التالي إذا كان Python مثبتاً:

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

**4. تشغيل Docker Desktop** والانتظار حتى يظهر أنه يعمل (Engine running).

**5. تشغيل المشروع**

```bash
docker compose up --build
```

عند أول تشغيل ينشئ Docker قاعدة البيانات `hirfati_db` وجداولها من `database/schema.sql`
ويضيف البيانات التجريبية من `database/seed.sql`، ثم يبدأ تطبيق Flask بعد جاهزية MySQL.

**6. فتح الموقع من المتصفح**

```
http://localhost:5000
```

إذا كان المنفذ 5000 مستخدماً على جهازك، غيّر `APP_PORT` في ملف `.env` (مثلاً `APP_PORT=8080`)
ثم افتح `http://localhost:8080`.

## طريقة إيقاف المشروع

إذا كان المشروع يعمل في نافذة الطرفية، اضغط `Ctrl + C`، ثم:

```bash
docker compose down
```

- **`docker compose down`** يوقف الحاويات ويحذفها فقط، أما **بيانات قاعدة البيانات فتبقى محفوظة**
  داخل الـ volume المسمى `hirfati_db_data`. عند التشغيل مرة أخرى بـ `docker compose up`
  تعود جميع الحسابات والطلبات والاشتراكات كما كانت.
- **`docker compose down -v`** يوقف الحاويات **ويحذف بيانات قاعدة البيانات نهائياً**.
  عند التشغيل التالي تُنشأ قاعدة بيانات جديدة من `schema.sql` و`seed.sql`.
  استخدمه فقط إذا أردت البدء من جديد.

## التشغيل بدون Docker (اختياري)

يتطلب Python 3.12 أو أحدث وخادم MySQL 8 يعمل على الجهاز:

```bash
mysql -u root -p < database/schema.sql
mysql -u root -p < database/seed.sql
cd backend
pip install -r requirements.txt
python app.py
```

مع ضبط `DB_HOST` و`DB_PORT` و`DB_USER` و`DB_PASSWORD` في ملف `.env` حسب خادم MySQL لديك.

## معلومات المشروع

### واجهة العميل
- تصفّح الخدمات (كهربائي، سباك، نجار، ... و«خدمات أخرى») والحرفيين حسب الخدمة والمحافظة.
- مشاهدة قسم «الحرفيون المميزون» (مشتركو Pro) في الصفحة الرئيسية.
- عرض ملف الحرفي وتقييماته، وإرسال طلب عرض سعر يتضمن وصف المشكلة والموقع.
- متابعة الطلبات في «طلباتي»: قبول عرض السعر أو رفضه، وتقييم الحرفي بعد إنجاز الخدمة.
- تقديم شكوى.

### واجهة الحرفي
- إنشاء حساب حرفي واختيار الباقة: **Basic** (مجانية) أو **Pro** (10 دولارات لمدة شهر عبر دفع تجريبي).
- مشترك Pro يحصل على شارة Premium وأولوية في قائمة الحرفيين ويظهر في قسم المميزين.
- إلغاء اشتراك Pro أو إعادة الاشتراك من الملف الشخصي.
- استقبال الطلبات، وإرسال عرض سعر (التكلفة، مدة التنفيذ، الموعد) أو رفض الطلب، وتحديد الطلب كمكتمل.
- تقديم شكوى.

### لوحة تحكم الأدمن
- إدارة المستخدمين (العملاء والحرفيين) وعرض تفاصيلهم.
- متابعة جميع الطلبات وحالاتها.
- متابعة الشكاوى وتحديث حالتها.
- مراقبة الاشتراكات: نوع الاشتراك وتواريخ الاشتراك والانتهاء والإلغاء وسجل كل حرفي.

### ملاحظات أمنية
- كلمات المرور مخزنة مشفّرة (hash) ولا تُحفظ كنص واضح.
- الصلاحيات يتم التحقق منها في الواجهة الخلفية لكل نوع حساب.
- الدفع تجريبي بالكامل: لا يتم الاتصال بأي بوابة دفع ولا يُحفظ رقم البطاقة أو CVV.
- ملف `.env` الذي يحتوي كلمات المرور لا يُرفع إلى GitHub.
